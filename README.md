# Trikks Reskins

A flat, minimalist reskin of Blizzard's windows, progress bars, gear slots and tooltips, plus clean square action buttons – for the **WoW Forever** client.

**Requires [Trikks Tweaks](https://github.com/jonasbaldewijns-afk/TrikksTweaks)** (it uses its settings hub and UI kit). Settings: **/trikks** → Reskin. Every window can be switched on or off; changes apply after a /reload.

## Install
Copy `TrikksReskins` (and `TrikksTweaks`) into `World of Warcraft\_forever_\Interface\AddOns\`.
